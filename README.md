# 地球奇迹与现代巨构 · Tellux

基于开源三维地球引擎 [Tellux](https://github.com/cyanfish-x/tellux) 与 Three.js 程序化建模，将 **古代文明奇迹**、**现代科技巨构**、**垂直摩天都市** 与 **跨海超级工程** 放置在真实经纬度与高精卫星地貌上。集成参数化几何装配、日/夜窗光矩阵、工程剖析模式与维基共享资源官方实景照片 1:1 对照系统。

各遗址与巨构按标志性结构做特征精细化建模（石作分层、拱券残垣、五边形同心环、500米抛物面索网、螺旋阶梯退台、蚝贝流线人工岛、贝壳张拉薄壳、海鸥波浪曲面顶棚等）。底图默认采用 **ArcGIS World Imagery** 卫星影像（零密钥即可开箱运行）。

单独查看模型：打开 `/preview.html?id=giza`（支持 `wall` / `petra` / `colosseum` / `chichen` / `machu` / `taj` / `christ` / `pentagon` / `fast` / `burj` / `apple` / `sydney` / `globalcenter` / `hzmb` / `goldengate` / `svalbard` / `liberty` / `defense`）。

## 核心系统与特性

### 1. 实景照片 1:1 对照系统
- 每一个地标在信息面板中均配备了源自 **Wikimedia Commons** 的高清晰度代表性实景照片。
- 遵循知识共享（Creative Commons）协议，完整标注照片原作者与来源出处链接。
- 3D 几何建模（结构、朝向、局部细部、配色材质）与实景照片保持严格的视觉对照标准。

### 2. 无人机 360° 航拍环绕
- 支持以恒定线速度围绕目标地标进行平滑的 360° 无人机轨道巡航。
- 支持键盘快捷键 `O` 或界面浮动按钮无缝切换启动与停止。
- 修复了环绕停止后光标事件穿透与相机状态冻结问题。

### 3. 全日光影追踪与 48 秒延时摄影
- **四大时段光影预设**：
  - 🌅 **晨曦 (Dawn, 06:00)**：清晨地平线横扫强斜射光，拉长建筑立体阴影。
  - ☀️ **正午 (Noon, 12:00)**：直射顶光，建筑明暗分明，色彩饱满。
  - 🌇 **黄昏 (Golden Hour, 17:45)**：斜阳夕照，暖橙色低角度长影。
  - 🌌 **静谧夜景 (Night, 22:30)**：深邃夜空，建筑自动激活窗光矩阵与艺术灯光。
- **实时太阳追踪与延时摄影**：
  - 按 `R` 键恢复与当地现实时间同步的真实太阳位置。
  - 点击「延时摄影」可以 48 秒完成一整天（24小时）的光影流转模拟。

### 4. 工程剖析系统（现代建筑专属）
- **📐 线框网格模式**：隐藏表面材质，显露高精度参数化结构骨架与三角形拓扑。
- **🌓 窗光夜景模式**：程序化激活立面随机窗光、建筑轮廓泛光灯与极地反射棱镜光纤。

### 5. 无抖动降落与锁定旋转轴心
- **防眩晕平滑进场**：飞行降落完成瞬间彻底清除累积角速度与惯性，根除了到达目的地瞬间镜头画面跳跃飘移的问题。
- **动态中心吸附**：相机的旋转轴心（`pivotPoint`）在降落后自适应吸附在建筑几何中心，旋转、平移、滚轮缩放均围绕建筑本体，永不丢失视野。

### 6. 📷 环球旅行明信片一键生成系统
- 任何地标下轻按键盘 `P` 键或点击控制台「📷 生成明信片」，自动隐藏多余 UI 图钉标记并捕获当前视角高精渲染画面。
- 自动合成博物馆画报与拍立得质感的纪念海报，包含：
  - 建筑中英文名称与落成年代；
  - 精确大地测量经纬度坐标与所属城市国家；
  - 当时当地日照与拍摄时间水印（如 `☀️ 正午 12:00` / `🌙 静谧夜景 22:30` / `📐 Pentagon3D 结构线框`）；
  - 官方 Earth Wonders 钢印与地标专属编号印章；
  - 支持一键导出并保存高清 PNG 壁纸图片。

### 7. 🌌 动态自然气候与大气粒子系统
- **斯瓦尔巴全球种子库**：
  - **北极极光（Aurora Borealis）**：真实呈现北极天际流动的翡翠绿与天青色极光波幔，在雪山脊线上随风轻漾；
  - **极地飞雪粒子**：谷地中漫天漂浮的 350 颗轻盈雪花粒子。
- **旧金山金门大桥**：
  - **低空流动海雾（Karl the Fog）**：还原旧金山海峡标志性的低空海雾层，穿行于大桥加劲桁架与 227 米国际橘双塔之间。

### 8. 🌐 网址深度视角链接（URL Deep Linking）
- 随时复制浏览器地址栏即可将当前地标、日照时段、剖析模式与航拍状态完整分享给好友（例如 `?id=liberty&time=night&orbit=1`）。
- 打开链接后自动直飞目标地标并精准复现完全相同的运镜、光影与模式。

## 操作指南

| 操作 | 作用 |
|---|---|
| **鼠标左键拖拽** | 旋转地球或围绕当前地标旋转环视 |
| **鼠标右键拖拽** | 平移视角 |
| **滚轮滚动** | 缩放距离（近距微观至全球宏观） |
| **分类胶囊（全部/古代/巨构/先锋/跨海）** | 筛选地标列表与地球标记 |
| **点击地标列表或地球标记** | 镜头平滑飞抵该地标并展开实景对照卡片 |
| **键盘 `1` ~ `9`** | 直达 1~9 号地标（吉萨至五角大楼） |
| **键盘 `0` / `-` / `=`** | 直达 10~12 号地标（FAST / 哈利法塔 / 苹果园区） |
| **键盘 `[` / `]` / `\`** | 直达 13~15 号地标（悉尼歌剧院 / 环球中心 / 港珠澳大桥） |
| **键盘 `;` / `'`** | 直达 16~17 号地标（金门大桥 / 斯瓦尔巴全球种子库） |
| **键盘 `,` / `.`** | 直达 18~19 号地标（自由女神像 / 巴黎拉德芳斯新凯旋门） |
| **键盘 `P`** | 一键生成并下载当前地标专属明信片壁纸海报 |
| **键盘 `T`** | 开始当前分类下的全自动环球巡礼（每站停留赏景） |
| **键盘 `O`** | 开启 / 停止 360° 无人机航拍环绕 |
| **键盘 `R`** | 重置为当地现实时间太阳光影 |
| **键盘 `Esc`** | 停止当前巡礼并返回外太空轨道视角 |
| **工程剖析栏** | 切换「📐 线框网格」与「🌓 窗光夜景」 |

## 本地开发与运行

需要 Node.js 18+。由于依赖树中的 Takram 包带有 React peer 依赖，本项目通过 `.npmrc` 中的 `legacy-peer-deps=true` 解决兼容（应用纯原生 TS/Three.js，无 React 运行时负担）。

```bash
cd EarthWonders
npm install
npm run dev
```

浏览器打开 `http://localhost:5173`。

Windows 用户亦可直接双击根目录下的 `start.bat` 脚本启动。

本地生产环境构建与预览：

```bash
npm run build
npm run preview
```

## 生产构建与 GitHub Pages 部署

本项目构建产物为 100% 纯静态文件（`index.html` + JS/CSS + 静态资源），无需任何后端服务器或专有数据库，零成本托管。

### 部署步骤：

1. 在 GitHub 上创建一个新的公开或私有仓库（例如 `EarthWonders`）。
2. 在本地执行推送：
   ```bash
   git init
   git add .
   git commit -m "feat: complete Earth Wonders on Tellux with 17 landmarks"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/EarthWonders.git
   git push -u origin main
   ```
3. 打开仓库 **Settings → Pages**，在 **Build and deployment** 下将 Source 切换为 **GitHub Actions**。
4. 推送至 `main` 后，官方 CI 自动完成依赖安装、构建并一键发布至 GitHub Pages。
5. 站点访问地址为：`https://<你的用户名>.github.io/EarthWonders/`
